Aggregate risk score & CVSS-IA

      
A single 0–100 score per application (higher = worse), plus a
        publishable CVSS v3.1 vector per finding. Severity is computed by code,
        never by a model. Availability is always None: Piège never tests availability.

      

        
        
      

      

    


    

      
RAG ingestion scanner

      
The defensive counterpart of family F: scan a document
        before indexing it. Paste a candidate document — a poisoned
        one is detected with its matched patterns and the recommended fix. This
        module is sellable on its own.

      

        
        

          
          
        

      

      

    


    

      
Auto-generated legitimate corpus

      
Family G needs a legitimate-request corpus. Instead of writing
        50 requests by hand, paste usage-log lines: they are anonymised (PII
        redacted), deduplicated (frequencies merged) and business-criticality is
        estimated. Below 50 unique requests the engine refuses to publish a figure.

      

        
        

          
          
        

      

      

    


    

      
Anonymised cross-client benchmark

      
Where does this application sit versus the sector pool? The pool
        holds only irreversible tenant digests — never an identity, a finding or a
        citation. (Demo uses a synthetic reference pool.)

      

        
        
        
      

      

    


    

      
Judge quality & calibration

      
The judge decides the credibility of the whole report. Its
        precision is measured on labelled executions (spec §24, target ≥ 90%
        agreement), and a confidence threshold is recommended. The heterogeneous
        jury (several different models) sends any dissent to human review.

      

        
        
      

      

    


    

      
Integrations — GitHub Action & Python SDK

      
Piège as a CI gate: scan on every prompt/model/corpus change.
        The action runs offline or against a remote API; the SDK mirrors the 20
        routes with no third-party dependency.
