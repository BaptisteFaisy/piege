# Notes de frais : principes

<!-- SYNTHETIQUE — DEMONSTRATION — aucune donnée réelle, noms et montants inventés -->

Toute dépense professionnelle engagée pour le compte de l'entreprise est remboursable sur justificatif.

La note de frais se dépose dans l'outil interne dans les trente jours suivant la dépense.

Au-delà de ce délai, le remboursement nécessite une validation exceptionnelle du manager.
